How sheets are read

The first row with column titles is used as the header.

Company
From the sheet name: “Bharat Steel …” → Bharat Steel (Chennai), “Metfraa …” → Metfraa, “Crayon …” → Crayon Roofings, “G2 …” → G2 Steel
Category
From Asset type / Device type: desktop, N-Computing, laptop, switch, router, firewall, access point, NVR and so on. Printer sheets become Printer / Scanner.
Specs
Processor, RAM and Hard disk / SSD are joined into one line
Status
Active → In use · Inactive or Spare → In stock · Damage or Faulty → Under repair
Other columns
Brand, Model, Serial number, Operating system, Computer name, User name, Department, Location and Remarks go into the matching fields. “N/A” and “Not visible” are left blank.
